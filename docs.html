Documentation

Dark Raider is a Discord bot for gaming communities. It tracks chat and voice activity, rewards members with levels, and can split a voice channel into two isolated teams.

Setup

1. Create the bot

  1. Open the Discord Developer Portal and click New Application.
  2. Go to the Bot tab and add a bot.
  3. Turn on Server Members, Message Content and Presence intents.
  4. Copy the bot token. Never share it.

2. Invite it

Use the invite link. It asks for Administrator, which team mode needs to move members and manage channels.

3. Configure and run

cp .env.example .env   # add DISCORD_TOKEN, channel IDs, role IDs
npm install
npm start

To copy IDs, enable Developer Mode (Settings → Advanced), then right-click a channel or role and choose Copy ID.

Configuration

Choose where each message type is posted with /setchannel <type> <channel>. Changes apply immediately.

Commands marked admin work for members with Administrator or the role set as ADMIN_ROLE_ID.

Levels & XP

Members earn XP for chat messages, with a 1 minute cooldown so spamming doesn’t help. Reaching the next level takes 100 × (level + 1)² XP, so each level needs more than the last.

  • /rank shows your level and progress.
  • /leaderboard lists the top 10, sorted by level then XP.
  • /dashboard opens buttons for rank, leaderboard and team status.

Voice tracking

Every minute in a voice channel earns XP. When a member leaves, the bot posts a summary with time spent, members in the channel and XP earned. /voicestats shows past sessions (the last 500 per server are kept).

FPS team mode

Admins can split one voice channel into two teams that only hear their own squad.

  1. /team setup and pick the voice channel.
  2. Assign players with /team assign, or run /team panel on to post buttons (Team 1, Team 2, All) so players choose.
  3. /team on creates two private channels under a “RAIDER TEAMS” category and moves each team in.
  4. /team off moves everyone back and deletes the temporary channels.

The bot needs Manage Channels, Move Members and Manage Permissions. The Administrator invite covers all three.

Soundboard control

Stop one member from using the voice Soundboard, without changing anything else about them.

/soundboard-block @member [channel1..channel5]
/soundboard-unblock @member [channel1..channel5]
/soundboard-status @member

The bot adds a member-specific overwrite that denies Use Soundboard and Use External Sounds. Leave the channel options empty to block every voice channel, including ones created later. Use /soundboard-status to see where a member is restricted and who set it.

The server owner and anyone with Administrator bypass channel permissions, so they can’t be restricted. You also can’t restrict someone whose top role is equal to or above yours. These commands are slash-only.

Welcome & boost messages

New members get a welcome message in the welcome channel. When someone boosts the server, the bot posts a thank-you and can grant a boost reward role. The bot’s status also rotates every 40 seconds (for example “Raider | Ready to Battle”).

All commands

The classic !raider prefix also works for rank, leaderboard, voicestats, dashboard, team, setchannel and help.

Hosting

For 24/7 uptime run the bot on Railway, Render, or a VPS with pm2 start index.js. To power the live status on this site, add bot-status-server.js to the bot and set status.mode to "api" in js/config.js.

Troubleshooting

ProblemFix
Slash commands don’t appearRe-invite with the applications.commands scope and wait a minute.
Team mode can’t move membersGive the bot Administrator, and place its role above the members it moves.
Soundboard block says “missing permissions”The bot role needs Manage Permissions in those channels.
Soundboard block has no effectThe member is the owner or has Administrator.
No XP or messagesCheck intents are enabled and channels are set with /setchannel.
Site shows “Status unavailable”Check status.apiUrl in js/config.js and that the bot host is running.
